# Mission 3 – Understand the Operating System

## 1. Task / Objective

The aim of this mission was to understand how an operating system manages processes, storage, files, paths and permissions.

## 2. Work Completed

- Checked the operating system and current account using Terminal.
- Checked available storage and observed running system activity.

- Practised navigating between folders and checking file permissions.
- Studied the main responsibilities of an operating system.

## 3. Commands / Tools Used

| Command | Purpose |
|---|---|
| `uname` | Displays the system name. |
| `whoami` | Shows the current account. |
| `df` | Displays storage information. |
| `top` | Shows running system activity. |
| `ps` | Lists running processes. |
| `pwd` | Shows the current directory. |
| `cd` | Changes the current directory. |
| `ls -l` | Shows files with their permissions. |

## 4. My Understanding

An operating system manages the computer's hardware and provides an environment for applications to run.

A process is a program that is currently running. Each process has a PID, which is its unique identification number.

An absolute path gives the complete location of a file or folder, while a relative path describes its location from the current directory.

File permissions control whether a user can read, write or execute a file.

I also learned about the main responsibilities of an operating system:

| Responsibility | Explanation | Example |
|---|---|---|
| Process management | Manages running programs. | Running Chrome and Terminal. |
| Memory management | Manages memory used by programs. | Allocating RAM to Chrome. |
| Device management | Manages connected devices. | Keyboard and printer. |
| File management | Organises files and folders. | Saving a document. |
| User interface / shell | Allows users to interact with the computer. | Desktop and Terminal. |
| Security and permissions | Controls access to files and resources. | Read and write permissions. |
