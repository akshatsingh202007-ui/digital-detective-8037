# Mission 5 – Numbers and Data

## 1. Task / Objective

The aim of this mission was to understand number systems, practise conversions, verify them using Python and learn how computers store text.

## 2. Work Completed

- Converted decimal, binary and hexadecimal numbers.
- Verified the conversions using Python.
- Created and tested a Python number converter.
- Learned about ASCII and UTF-8 encoding.

## 3. Commands / Tools Used

| Command / Function | Purpose |
|---|---|
| `touch` | Creates an empty file. |
| `python3` | Runs Python programs. |
| `input()` | Takes input from the user. |
| `int()` | Converts a value into an integer. |
| `bin()` | Converts a number into binary. |
| `hex()` | Converts a number into hexadecimal. |

## 4. My Understanding

Binary uses base 2, decimal uses base 10 and hexadecimal uses base 16.

I used Python's built-in functions to check my manual calculations. I also learned that computers use character encoding standards like ASCII and UTF-8 to represent text.

The number converter takes a decimal number from the user and displays its binary and hexadecimal forms.
