# Mission 1 – Know Your Computer

## 1. Task / Objective
The aim of this mission was to understand how a computer works, how it processes information and the difference between hardware and software. I also explored some computer-based systems that we use in everyday life.

## 2. Work Completed

### Task 1.1 – Understanding IPOS

I chose the example of searching for something on Google using my MacBook.

| Stage | What happens? | Hardware / Component |
|---|---|---|
| Input | I type what I want to search using the keyboard. | Keyboard |
| Processing | The computer processes my search request and the browser handles the website request. | CPU and RAM |
| Output | The search results appear on my screen. | Display |
| Storage | The browser may save browsing data and I can save useful information for later. | SSD |

### Task 1.2 – Hardware and Software

Hardware refers to the physical parts of a computer that we can touch, whereas software consists of programs that run on the computer.

**Hardware**

| Item | Type | Purpose |
|---|---|---|
| Keyboard | Hardware | Used to enter text and commands. |
| Mouse / Trackpad | Hardware | Used to control the pointer and interact with the computer. |
| Monitor | Hardware | Displays information and results. |
| SSD | Hardware | Stores files, applications and other data. |
| Processor (CPU) | Hardware | Executes instructions and processes data. |

**Software**

| Software | Type | Purpose |
|---|---|---|
| macOS | Operating System | Manages the computer and its resources. |
| Google Chrome | Application Software | Used for browsing websites. |
| Visual Studio Code | Application Software | Used for writing and editing code. |
| Homebrew | Utility Software | Helps install and manage software packages. |
| Terminal | Application Software | Allows me to interact with the computer using commands. |

### Task 1.3 – Computer Systems Around Us

Apart from laptops and mobile phones, there are many computer-based systems that we use regularly.

| System | Main Purpose | Input | Output |
|---|---|---|---|
| ATM | Used for banking and withdrawing money. | Card and PIN | Cash and transaction details |
| Traffic Signal | Controls the movement of vehicles. | Timer or sensor input | Traffic lights |
| Ticket Vending Machine | Used to purchase tickets. | Destination and payment | Printed ticket |

## 3. Commands / Tools Used
- MacBook and macOS – Used to explore the computer system.
- Google Chrome – Used as an example of an application.

## 4. My Understanding
Through this mission, I understood how input, processing, output and storage work together to perform everyday tasks. I also learned that hardware and software depend on each other. Hardware provides the physical components, while software tells those components what to do.
