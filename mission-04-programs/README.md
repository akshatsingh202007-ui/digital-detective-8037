### Task 4.2 – Compiler vs Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation happens | Before execution | During execution |
| Typical output | Often creates an executable file | Executes instructions directly |
| Example | C, C++ | Python |
| One advantage | Can produce faster-running programs | Easier to test and debug |

A compiler translates the program before it runs, whereas an interpreter executes the code during runtime. Compilers often create a separate executable file, while interpreters execute instructions directly. Both approaches are used to run programs.
